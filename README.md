# Omkar Mohite — Portfolio

Personal portfolio website for Omkar Mohite, a Full Stack Developer focused on Angular and .NET.

## Core technology
- Angular 21, TypeScript, RxJS
- C#, .NET, ASP.NET Core Web API
- SQL Server, Dapper, Entity Framework Core, stored procedures
- REST API integration and JWT authentication
- Angular microfrontend architecture
- WPF and .NET desktop application development
